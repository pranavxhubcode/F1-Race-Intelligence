# Formula 1 — Race Intelligence Dashboard

## Project Overview
An interactive Formula 1 data analysis dashboard built using Tableau Public to explore driver performance, season-wise points trends, and constructor performance.

## Dashboard Features
- **Top 20 Drivers by Points:** Compares drivers based on total points.
- **Lewis Hamilton — Points by Season:** Shows his points trend across seasons.
- **Top 10 Constructors by Points:** Compares constructor performance.

## Tools and Technologies
- Tableau Public
- CSV datasets
- Data visualization and analysis

## Project Files
- `master_analysis.csv` — Main analysis dataset
- `circuits.csv` — Circuit information
- Tableau workbook — Dashboard workbook
